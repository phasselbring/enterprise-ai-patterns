# Director of Staff: Executive Workflow Method

**Governed AI work at a measured cost per accepted result.**

A portable, *methodology-only* Agent Skill by **Paul Hasselbring**, founder of **NPM Technologies, Inc.** This preview helps executive teams describe work orders, choose the lowest-sufficient-cost approach, structure evidence, and identify decisions that must remain under human control.

**Start here:** [SKILL.md](SKILL.md)

## What this release includes

- Decision-oriented instructions for prioritization, routing, evidence, and escalation.
- [Synthetic sample work order](examples/vendor-intake.md), with no customer or employer data.
- [Work-order template](references/work-order-template.md).
- [Measurement guide](references/measurement-guide.md) focused on human minutes saved and total cost per accepted result.

This preview is **not** the proprietary Director of Staff engine, a security gateway, a working task scheduler, a deployment system, or a certification. A skill's instructions do not independently enforce access control, approvals, audit integrity, or system isolation. It must not be described as enterprise-ready autonomous software.

## How to try it

Copy the `director-of-staff-executive-workflow` directory into a compatible agent's skills directory, or supply `SKILL.md` as task instructions. Support and installation commands vary by agent platform. Start with the synthetic example, have a reviewer evaluate the response, and do not grant the model uncontrolled external actions.

For the general skill format, see [Agent Skills specification](https://agentskills.io/specification).

## Positioning

The public methodology demonstrates *how to think about* efficient governed work. Actual enforcement requires independently tested application code, identity and authorization controls, and auditable operational workflows. The public release does not contain NPM's private Director of Staff orchestration implementation or APEX policy engine.
